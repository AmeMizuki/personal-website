這是一篇範例日誌條目,現在用 **Markdown** 撰寫。

這個頁面示範了條列樣式、日期欄位、以及 `/journal/:slug` 的路由。內文支援標準 Markdown 語法:

- 條列項目
- **粗體**、*斜體*
- [連結](https://example.com)
- `行內程式碼`

```js
// 也支援程式碼區塊
console.log('hello, journal')
```
