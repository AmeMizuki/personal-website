這個網站是我自己動手架起來的小天地，主要用 Astro 和 Markdown 整理內容，再透過 GitHub Pages 發佈到網路上。選 GitHub Pages 很單純：免費、設定方便，也能很快把網站上線。之後有新東西想分享，就慢慢加進來。

現在目前有的功能是首頁的終端機指令功能，若對 Linux 系統指令很熟悉的人，可以使用 Linux 系統的指令來導覽，算是一種互動式的小樂趣之一。原本預計是打算做個彩蛋的，但我擔心會增加網頁的使用效能問題，雖然可以優化等，不過這依然是我分享學習經歷和技術的網誌，也不代表未來沒有這份考慮，畢竟我將來是想試試看做個小遊戲...。

除此之外也會分享一些免費內容，例如目前有哪些開源專案的工具適合用在哪個場景，我會先使用看看，得出心得後再來總結，不過也不是每個工具介紹每個都會去測試，我也會看別人評測後，分析總結得出個概論。
