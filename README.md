# 個人網站

一個以終端機風格呈現的個人網站，結合深色介面、ASCII 動態背景，作為自我介紹、分享日常與展示作品的空間。

## 網站用途

- **關於我**：介紹個人背景、興趣與聯絡方式。
- **日誌**：記錄生活、心得與較完整的文章；列表頂部提供精簡 RSS 按鈕，可開啟 `/rss.xml` 並將網址加入閱讀器，介面支援中英文切換。
- **筆記**：分享短篇想法與隨手記錄。
- **作品**：展示專案、使用工具、連結預覽卡，以及可切換和放大的多圖相簿。
- **連絡我**：透過 footer 進入需求表單，同意隱私權政策後投遞郵件。

## 使用工具

- **Astro、Vue 3**：Astro 預先產生頁面，Vue 在需要互動時啟用元件。
- **Tailwind CSS、shadcn-vue**：用工具類別與現成元件建立一致的介面。
- **GSAP**：控制文字與介面的動畫效果。
- **Markdown**：將文章與筆記轉成網頁內容。
- **Utterances**：透過 GitHub Issues 提供文章留言。
- **FormSubmit**：處理聯絡表單與防垃圾郵件驗證，將需求寄至個人信箱。

## SEO、狀態與載入

- **SEO**：提供頁面摘要、分享資訊與結構化資料，並產生網站地圖，協助搜尋引擎理解內容。
- **狀態管理**：透過 Vue 的響應式狀態同步語系、播放器與目前頁面，並在瀏覽器保存偏好與指令歷史。
- **Loading / lazy loading**：載入與換頁時顯示提示，非必要的互動元件、圖片與留言延後載入，優先呈現主要內容。
- **閱讀時間**：日誌依內文估算，排除程式碼區塊；只有 frontmatter 的空文章仍可開啟，顯示最低 1 分鐘。

## 開發

使用 Node.js 24，首次開發先安裝鎖定版本的依賴：

```sh
npm ci
npm run dev
npm run build
npm run preview
```

同一個專案目錄只執行一個 `astro dev`；安裝依賴或執行 `astro build` 前，先停止開發程序，完成後再啟動。不同 port 仍會共用 `.astro`／Vite 快取，同時寫入可能造成 `data-store.json.tmp` 的 `ENOENT` 或模組載入失敗。
