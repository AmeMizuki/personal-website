# 個人網站

一個以終端機風格呈現的個人網站，結合深色介面、ASCII 動態背景，作為自我介紹、分享日常與展示作品的空間。

## 網站用途

- **關於我**：介紹個人背景、興趣與聯絡方式。
- **日誌**：記錄生活、心得與較完整的文章。
- **筆記**：分享短篇想法與隨手記錄。
- **作品**：展示專案、使用工具與相關連結。

## 使用工具

- **Astro、Vue 3**：Astro 預先產生頁面，Vue 在需要互動時啟用元件。
- **Tailwind CSS、shadcn-vue**：用工具類別與現成元件建立一致的介面。
- **GSAP**：控制文字與介面的動畫效果。
- **Lucide**：提供介面圖示。
- **Markdown**：將文章與筆記轉成網頁內容。
- **Utterances**：透過 GitHub Issues 提供文章留言。

## SEO、狀態與載入

- **SEO**：提供頁面摘要、分享資訊與結構化資料，並產生網站地圖，協助搜尋引擎理解內容。
- **狀態管理**：透過 Vue 的響應式狀態同步語系、播放器與目前頁面，並在瀏覽器保存偏好與指令歷史。
- **Loading / lazy loading**：載入與換頁時顯示提示，非必要的互動元件、圖片與留言延後載入，優先呈現主要內容。

## 開發

```sh
npm run dev
npm run build
npm run preview
```
